Why we built SandEE

Learning to program is hard. Traditional lessons lean on theory and static exercises, which struggle to hold students’ attention or prepare them for real problem-solving. Game-based learning changes that: it makes practice interactive, contextual, and fun.

We surveyed 104 ICT and STEM students at Yverdon de Pestalozzi School Inc. and found that most were only averagely familiar with Lua — yet the large majority believed a game would improve their understanding and motivate them to explore it. Interest was clearly there; the right tool was not.

SandEE is our answer. It embeds real Lua and Python interpreters into a 2D open-world survival crafting game, so the code you write actually affects the world around you. A mission system introduces syntax gradually, and visual feedback turns abstract concepts into things you can see, break, and fix — just like in a real programming environment. Every new save begins in a freshly generated world, and cross-platform cloud saves let you continue on Windows or Android.

Our objectives

  • Enhance programming skills through hands-on, experience-based learning.
  • Provide direct visual feedback as players learn and apply concepts.
  • Respond realistically to player code — errors included — via embedded interpreters.
  • Introduce the structure and syntax of Lua and Python in a natural progression.
104 ICT & STEM students surveyed (Grades 11–12)
78.9% agreed game-based learning would improve their understanding
73% were motivated to explore Lua through an interactive approach
80.8% found Python’s syntax and structure easy to understand
